# Screenshot provenance

- `products-desktop.png`: actual local Chromium rendering of the Sally widget, 900px wide. Illustrative fixture data; not current product prices and not a ChatGPT-host screenshot.
- `products-mobile.png`: same widget at 390px wide; layout and horizontal overflow tested. Illustrative fixture data.

`consent-runtime.png` is the actual consent page rendered by the isolated workerd OAuth test with a synthetic client. It verifies that Deny submits without an email; it is not account sign-in or ChatGPT-host proof.

Product previews are generated by `npm run test:ui`; consent is generated by `npm run test:runtime`. No product purchase or basket modification occurred.

Actual ChatGPT installation was observed in the Plugins directory, but the browser policy blocked further app-page access before a host screenshot or in-chat widget check could be completed. That host evidence remains a release blocker; these standalone UI images are not a substitute for it.

Branding previews were refreshed for Sally by HeySalad® using the actual HeySalad icon. The live private ChatGPT app name/description were updated, but that settings screen is not an in-chat widget screenshot and is not included as a submission marketing image.
